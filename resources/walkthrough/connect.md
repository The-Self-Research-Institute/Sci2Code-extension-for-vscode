# Connect your Zotero library

1. Open [zotero.org/settings/keys](https://www.zotero.org/settings/keys) and create a new private key.
2. Tick **Allow library access**. Also tick **Allow write access** if you want manual citations saved to your library.
3. Run **Sci2Code: Login to Zotero** and paste the key.

Your papers then appear in the **Zotero** view in the Activity Bar. The library is cached, so it opens quickly next time.
