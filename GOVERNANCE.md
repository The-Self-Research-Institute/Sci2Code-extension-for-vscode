# Sci2Code Governance

## Purpose and Scope

The Sci2Code project aims to bridge the gap between scientific research and software development by linking code in our app to peer-reviewed scientific articles. This governance document outlines the rules, roles, and responsibilities to ensure transparency, accountability, and scientific integrity throughout the project's lifecycle.

## Objectives

Ensure that all code in the Sci2Code app is traceable to scientific literature where applicable.
Promote collaboration and inclusivity among contributors.
Maintain a high standard of scientific rigor and reproducibility.
Establish a clear process for managing contributions, reviews, and updates.

## Roles and Responsibilities

### Core Team

Responsible for the overall vision, strategy, and maintenance of the project.
Responsibilities:
Define project goals and milestones.
Review and approve major changes to the codebase.
Ensure adherence to this governance document.

### Contributors

Open to anyone willing to contribute code, documentation, or scientific references.
Responsibilities:
Submit well-documented code with references to relevant scientific articles.
Follow coding and documentation standards set by the Core Team.
Participate in peer reviews.

### Review Board

A group of experts in software development and scientific research.
Responsibilities:
Verify the scientific accuracy of references linked to the code.
Ensure code aligns with project goals and standards.
Resolve disputes in contributions or code reviews.

## Code-Scientific Linkage

### Guidelines for Linking Code to Articles

Each significant function or feature in the app should have associated scientific backing.
Scientific references must be:
Peer-reviewed.
Relevant and directly supportive of the code.
Cited in the comments and documentation.
